# Omnifood 🍽️

A responsive food delivery website built with HTML, CSS, and JavaScript. Omnifood is a fictional AI-powered meal delivery service designed to help people eat healthy meals every day without the hassle of planning and cooking.

## 🌐 Live Demo

[View Live Website](#)

## ✨ Features

- **Responsive Design** — Works across desktop, tablet, and mobile devices.
- **Modern UI** — Clean layout with consistent typography, spacing, and colors.
- **Mobile Navigation** — Responsive navigation menu for smaller screens.
- **CSS Grid & Flexbox** — Flexible layouts for different sections.
- **Sass (SCSS)** — Modular stylesheets for better organization and maintainability.
- **Testimonials** — Customer reviews and food photography.
- **Pricing Plans** — Meal subscription plans and features.
- **Smooth Navigation** — Links to different sections of the page.
- **Optimized Images** — Images optimized for improved loading performance.

## 🚀 Getting Started

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd omnifood
   ```

3. Open the project in Visual Studio Code.

4. Run the website using the Live Server extension, or use your configured development setup for compiling Sass.
